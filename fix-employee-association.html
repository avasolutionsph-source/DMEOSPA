🔧 Fix Employee Association

This tool fixes the issue where employees added in PWA don't appear in the marketing website.

⚠️ Important: You need tokens from BOTH the PWA and Marketing website for this to work properly.

📱 PWA Token

From PWA where you see employees

Get from PWA console: localStorage.getItem('authToken')

🌐 Marketing Token

From marketing website dashboard

Get from Marketing console: localStorage.getItem('userToken')

Step 1: Check Current Context

This shows which user context the employees are associated with

Step 2: Migrate Employees

This will associate all employees with the business owner account so they appear everywhere
