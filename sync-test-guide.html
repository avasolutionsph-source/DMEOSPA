Complete guide to sync data and view detailed reports

1

📱 Setup PWA

First, open and login to your PWA:

2

➕ Add Test Data

In the PWA, add test data:

  • Employees: Add 2-3 employees with commission rates
  • Products/Services: Add some spa services
  • Transactions: Create test sales in POS

Important: Select an employee when creating transactions!

3

⚙️ Configure Sync

In PWA Settings, set the API URL:

API URL: http://localhost:3001

This connects your PWA to the marketing website backend.

4

🔄 Sync Data

In PWA Settings, click "Sync Now" button.

Watch the console for sync messages:

✅ Products sync successful
✅ Employee sync successful
✅ Transaction sync successful
5

📈 View Dashboard

Open the Business Dashboard:

Open Dashboard

You should now see:

  • Today's Sales (if transactions are from today)
  • This Month's Sales
  • This Year's Sales
  • Employee performance data
6

📄 Generate Report

Click "Download Report" to see the full business report with:

  • Business statistics
  • Time-based sales data
  • Employee performance rankings
  • Commission calculations

⚠️ Important Notes

  • Date Matters: Transactions are grouped by date. Today's sales only show transactions from today.
  • Employee Assignment: Transactions without an assigned employee won't count toward employee metrics.
  • Sync Direction: Data flows from PWA → Backend → Dashboard (not the other way).

🔧 Troubleshooting

Reports showing ₱0.00?

  • ✅ Ensure you have transactions in the PWA
  • ✅ Check transaction dates (old transactions won't show in "Today's Sales")
  • ✅ Verify sync completed successfully (check PWA console)
  • ✅ Refresh the Business Dashboard after syncing

Employee data not showing?

  • ✅ Add employees in PWA first
  • ✅ Assign employees to transactions in POS
  • ✅ Run sync from PWA Settings
  • ✅ Check employee IDs match between employees and transactions

Quick Test Commands

Open browser console (F12) in PWA and run:

// Check local data
const db = new Database();
await db.init();
const transactions = await db.getAll('transactions');
console.log('Transactions:', transactions);
const employees = await db.getAll('employees');
console.log('Employees:', employees);

// Manual sync trigger
const sync = new SyncManager();
await sync.syncAll();
